**Approved Source List**

Reference guide for agent-led external research

Version 0.1 | 05/06/2026 | For internal pilot use

# 1\. Purpose

This document lists preferred sources for the agent's external research. The agent should prioritise these source categories and record all sources used.

# 2\. Source categories

| **Research area**                  | **Preferred sources**                                                                                                                                                                                 |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Market and company research        | Company websites; annual reports; press releases; Gov.uk; UKRI; Innovate UK; Companies House; industry associations; regulator websites; standards bodies; reputable market reports where accessible. |
| Patent and prior-art research      | Google Patents; Espacenet; WIPO Patentscope; The Lens; USPTO; UK IPO.                                                                                                                                 |
| Publication and academic landscape | OpenAlex; Crossref; PubMed; Semantic Scholar; institutional repositories; journal websites; funder databases.                                                                                         |
| Funding routes                     | UKRI; Innovate UK; NIHR; EPSRC; Horizon Europe; regional innovation programmes; KTP information pages; charity/foundation funders.                                                                    |
| Standards and regulation           | BSI; ISO; IEC; CEN/CENELEC; MHRA; HSE; ICO; FCA; Ofcom; Environment Agency; sector regulators.                                                                                                        |
| Contact research                   | Company team/leadership pages; press releases; public professional profiles; existing CRM records supplied by user; approved licensed contact databases only.                                         |

# 3\. Search and citation expectations

- Use non-confidential search terms only unless the user authorises otherwise.
- Prefer primary and official sources.
- Record source title, publisher, URL, date and relevance.
- Label source confidence as high, medium or low.
- If web search cannot be performed, provide manual searches for the user to run.
