**Figure and Table Standards**

Quality-control document for report outputs

Version 0.1 | 05/06/2026 | For internal pilot use

# 1\. Purpose

This document defines the required tables and decision-support figures for Innovation Commercialisation Exploration Reports.

# 2\. Required tables

| **Table**                            | **Purpose**                         | **Required columns**                                                                             |
| ------------------------------------ | ----------------------------------- | ------------------------------------------------------------------------------------------------ |
| Extracted innovation profile         | Summarise disclosure data and gaps. | Field; extracted information; confidence; notes/missing information.                             |
| Market applications                  | Rank market opportunities.          | Rank; application; sector; customer/user; problem; evidence/source; attractiveness; confidence.  |
| Prior art and competing technologies | Compare existing solutions.         | Type; title/name; organisation/authors; relevance; similarity; differentiation; risk; source.    |
| Company matching                     | Rank potential partners.            | Rank; company; country; sector; evidence of fit; engagement route; priority; confidence; source. |
| Contact strategy                     | Guide responsible outreach.         | Company; target role/contact; reason; route; source; compliance notes; confidence.               |
| Development roadmap                  | Plan translational development.     | Stage; objective; activities; evidence; funding/partner route; timeframe; risks.                 |
| Risk register                        | Capture decision risks.             | Risk category; description; severity; likelihood; mitigation; owner/reviewer; status.            |
| References                           | Audit evidence.                     | Claim/section; source title; publisher; URL; date; confidence.                                   |

# 3\. Required figures

| **Figure**                                    | **Purpose**                                                        | **Format**                     |
| --------------------------------------------- | ------------------------------------------------------------------ | ------------------------------ |
| Technology-to-market map                      | Show how capabilities map to applications and value propositions.  | Table or SmartArt map.         |
| Market attractiveness matrix                  | Prioritise applications by attractiveness and adoption difficulty. | 2x2 or scatter matrix.         |
| Competitive positioning matrix                | Show differentiation against substitutes.                          | 2-axis positioning plot.       |
| Company relevance vs ease-of-engagement chart | Prioritise partner targets.                                        | 2-axis matrix or bubble chart. |
| Development roadmap                           | Show milestones and decision gates.                                | Timeline/roadmap.              |
| Commercialisation route decision tree         | Explain route recommendation.                                      | Decision tree.                 |

# 4\. Scoring rules

- Use 1–5 scoring for figure axes unless quantitative data is available.
- Explain all scoring assumptions.
- Do not imply precision where evidence is qualitative.
- Mark low-confidence scores clearly.
- Figures must support a decision; avoid decorative visuals.

# 5\. Caption standard

Each figure must include: figure number, title, one-sentence purpose, data source/assumption note and interpretation.
